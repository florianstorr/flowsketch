# FlowSketch

Interaktiver 2D-Windkanal (Lattice-Boltzmann auf der GPU) zum Skizzieren mit dem Apple Pencil.
Eine eigenständige Web-App ohne externe Abhängigkeiten.

## Auf dem iPad einrichten

1. Die GitHub-Pages-Adresse dieses Repos in **Safari** öffnen.
2. Teilen-Symbol → **Zum Home-Bildschirm** → Hinzufügen.
3. Die App einmal mit Internet starten. Danach läuft sie auch offline.

## Aktualisieren

`index.html` ersetzen und hochladen. Die App lädt neue Versionen im Hintergrund und nutzt sie ab dem nächsten Start.
